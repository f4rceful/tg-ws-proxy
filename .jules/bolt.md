## 2024-06-25 - Python Endianness Optimization for int.from_bytes
**Learning:** For bitwise operations on arbitrary large chunks of byte data via `int.from_bytes` and `.to_bytes`, forcing `'big'` endianness on little-endian platforms (like most x86/ARM) incurs an unnecessary 10-15% overhead. `sys.byteorder` is noticeably faster for these scenarios where endianness doesn't mathematically matter (e.g. XOR masking). Also, multiplying string segments and adding remainder slices is faster than doing string multiplication of the rounded quotient and then slicing the entire result string down.
**Action:** Always prefer `sys.byteorder` when converting large unformatted byte chunks to integers strictly for symmetric bitwise math, and avoid generating excessive intermediate string/byte sequences.
